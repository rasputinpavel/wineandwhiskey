# Приходы — content pipeline (skill `arrivals`)

**Date:** 2026-07-17
**Status:** Approved (design)

## Problem

Каждая новая партия вина, приходящая в магазин, должна получать короткое
описание — что это за вино, почему оно интересное — с фотографиями, и
раскладываться в два канала «новинок»:

- **Telegram** — на русском
- **WhatsApp** — на английском

Каналы — для клиентов, интересующихся новинками. Сейчас подписчиков нет;
цель — начать постить регулярно и подписывать людей со временем.

## Decisions (из брейншторма)

| Вопрос | Решение |
|---|---|
| Публикация | **Ручная.** Скилл выдаёт готовый текст (RU + EN) + подобранные фото; пользователь копирует и постит сам. Никакой авто-публикации, никакого WhatsApp API, никакого нового бота. |
| Формат постов | **Один пост на партию (темой).** Групповое фото + по одной строке на бутылку. Совпадает с тем, как приходы фотографируют. |
| Роль Алана | **Подход C — «мозг Алана в скилле» сейчас, команда бота потом.** Скилл переиспользует исследовательскую «лесенку» Алана и его правило честности. Промоушен в `/arrival` у бота Алана — позже, если поток оправдает. |
| Цены | **Всегда спрашиваем у пользователя.** В inventory не лезем. Нет цены → плейсхолдер `XXX ฿`. |
| Хранение | `05_creative/output/YYYY-MM-DD_arrivals/` — `arrivals_ru.md`, `arrivals_en.md`, фото переезжают из `.inbox`. |

## Разделение голоса

Два слоя, чтобы не смешивать факты и тон:

| Слой | Источник | Что даёт |
|---|---|---|
| **Факты** | Мозг Алана (`01_agents/alan/src/sommelier-prompt.ts` — та же лесенка) | producer standing, сорт × страна × регион, окно питья, «почему интересно», честность (не выдумываем рейтинги/цены) |
| **Тон** | Редполитика соцсетей (`.claude/skills/social`) | коротко, конкретно, без хайпа; НЕ вердикт «бери/пропусти»; НЕ Alan-измы в лоб; имена вин в оригинале |

Алан-как-сомелье выносит вердикт клиенту («бери/пропусти»). Пост приходов —
мягкий продукт-контент: берём у Алана правду и «почему интересно», но тон —
«друг с хорошим вкусом, который не читает лекций».

## Пайплайн (на каждую партию)

1. **Разбор фото** — определить каждую бутылку: producer, wine, сорт, регион, винтаж.
2. **Ресёрч (лесенка Алана)** — по каждой бутылке: standing производителя, что
   значит этот сорт из этой страны/региона, окно питья, одна конкретная
   вкусовая нота, «почему интересно». Веб-поиск; не выдумываем факты; если
   данных по точной бутылке нет — читаем по производителю/категории.
3. **Цены** — запросить у пользователя (текстом). Нет → `XXX ฿`.
4. **Сборка поста партии:**
   - Заголовок-тема партии (из реплики пользователя, напр. «Серьёзные американцы»).
   - По одной строке на бутылку: `Имя · сорт/регион/винтаж · 1 нота · цена ฿`.
   - Мягкий CTA в конце (заходите / напишите нам).
5. **Два языка** — RU (Telegram) и EN (WhatsApp). Имена вин — в оригинале.
6. **Архив** — записать `arrivals_ru.md` + `arrivals_en.md` в дату-папку,
   перенести фото из `.inbox`.

## Границы (YAGNI)

- Нет авто-публикации, нет WhatsApp/Telegram API, нет нового бота.
- Нет лукапа цен в Supabase (пользователь диктует).
- Нет генерации фото — используем присланные снимки как есть.
