# Wine & Whiskey — B2B Sales Kit

**Purpose:** First-touch + leave-behind material for B2B outreach to Phuket beach clubs, cocktail bars, yacht provisioners, and hotel F&B teams.

**Audience:** Non-Russian buyers. F&B managers, head bartenders, beverage directors, marina provisioning managers.

**Positioning rule:** Lead with **product** and **commercial value**, not with origin. Russia is disclosed truthfully but mentioned once, in small type, near the bottom of each sheet. The buyer is not buying "Russian wine" — they are buying a rosé sparkling that fits their cocktail program at a price point that protects their bottle-service margin.

## Files in this kit

| File | Use |
|------|-----|
| `rose-sparkling.md` | Tear-sheet for Abrau-Durso rosé sparkling. Lead with beach clubs, yacht provisioning, by-the-glass programs. |
| `gin-range.md` | Tear-sheet for the gin range. Lead with cocktail bars, hotel lobby bars, signature-cocktail venues. |

## How to use

1. **First-touch (digital):** Send the relevant single tear-sheet as PDF attachment + 2-line WhatsApp message. Never send both at once unless the buyer's program covers both categories.
2. **In-person leave-behind:** Print A4 single-sided. Hand over after a tasting, never before.
3. **Pricing in the kit is a *band*, not a quote.** Every account gets a written quote on letterhead after the dialogue.

## Placeholders to fill in before printing/sending

These tear-sheets are **drafts** with structural placeholders marked `[TBD: ...]`. Fill in before any external use:

- [ ] Specific SKU names + bottle sizes for each gin expression
- [ ] ABV per SKU
- [ ] Case configurations (6×750ml vs 12×750ml, etc.)
- [ ] Case price band in THB (wholesale)
- [ ] MOQ (case minimum per order)
- [ ] Delivery zones + cut-off times
- [ ] Lead time for first order
- [ ] Sales rep name + phone once hired
- [ ] Photo of bottle line-up (catalog-quality)
- [ ] Add an importer license / FDA registration line if buyers ask for it

## Design notes (for whoever turns this into PDF)

- A4, single-sided, single page each.
- Brand: see `04_brand/` for tokens, logo, type system.
- Imagery: bottle hero or cocktail-in-context, never lifestyle of drinkers' faces. Match Instagram visual direction (light mode, travertine, hands/forearms, no faces).
- Origin line in 8pt at the foot of the page, e.g. "Produced by Abrau-Durso, Krasnodar Krai. Imported by Wine & Whiskey Phuket."
