# Bottle-neck shelf labels — 2026-08-24

Пять навесных воблеров, которыми размечаются бутылки на полке. Второе поколение
после [ревью-воблера от 2026-07-04](../2026-07-04_neck-tags-review/) — шире, короче
и с бо́льшим отверстием.

## Что поменялось против прошлого воблера

| | 2026-07-04 (ревью-тег) | 2026-08-24 (эти лейблы) |
|---|---|---|
| Формат | 62 × 128 мм, вертикальный | **85 × 80 мм, горизонтальный** |
| Отверстие | Ø 27 мм — не налезало, резали руками | **Ø 34 мм** — проходит поверх колпачка |
| Перекрытие этикетки | доходил до середины этикетки | низ воблера ≈ верх этикетки |
| Печать | 1 тег на лист | **6 на A4**, встык, под гильотину |

## Набор

| Лейбл | Цвет | Подпись |
|---|---|---|
| **BESTSELLER** | золото / чёрный низ | OUR CUSTOMERS' FAVOURITE |

| **SPECIAL OFFER** | винный / белый низ | панель под цены от руки |
| **LAST BOTTLES** | графит / золотой низ | WHEN THEY'RE GONE, THEY'RE GONE |
| **SOMMELIER'S CHOICE** | крем / винный низ | PICKED BY OUR SOMMELIER |

### Special offer — как заполнять
Две ячейки. В серую **WAS** пишешь старую цену — диагональ уже напечатана, писать
поверх неё, отдельно зачёркивать не надо. В белую с золотой рамкой **NOW** — новую.
Знак ฿ подсказкой стоит в обеих. Нужен перманентный маркер с тонким стержнем;
картон обязательно матовый, на глянце маркер не сохнет.

## Перед тиражом — проверить отверстие

Стр. 6 PDF — калибр: кольца Ø32 / 34 / 36 / 38 мм. Вырезать, надеть на реальные
бутылки. Прошлый раз промахнулись именно здесь. Ø34 рассчитан на стандартный
винный колпачок; игристому с мюзле может понадобиться Ø36–38. Если так —
скажи диаметр, перевыпущу файл.

## Пересборка

```bash
cd 05_creative/output/2026-08-24_neck-labels
python3 build_labels.py
CH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CH" --headless=new --no-pdf-header-footer \
  --print-to-pdf=neck-labels_2026-08-24_PRINT.pdf "file://$PWD/neck-labels_2026-08-24_PRINT.html"
"$CH" --headless=new --screenshot=neck-labels_2026-08-24_preview.png \
  --force-device-scale-factor=3 --window-size=1180,760 "file://$PWD/neck-labels_2026-08-24.html"
```

Геометрия и палитра — константы в шапке `build_labels.py` (`W`, `H`, `HOLE_D`,
`HOLE_TOP`, список `LABELS`). Новый лейбл = одна строка в `LABELS`.
