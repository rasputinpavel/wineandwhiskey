# Print specs — neck-tag "The Waiting Cat" (pilot)

Hand this to the print shop together with `neck-tag_waiting-cat_2026-07-04_PRINT.pdf`.

## The file
`neck-tag_waiting-cat_2026-07-04_PRINT.pdf` — 3 pages:
1. **Front** (artwork, with bleed)
2. **Back** (artwork, with bleed)
3. **Die-line / cut guide** (magenta = cut lines; does NOT print — reference only)

## Specifications
| Item | Value |
|------|-------|
| Trim size | **62 × 128 mm** (portrait) |
| Bleed | **3 mm** all sides (page is 68 × 134 mm) |
| Safety margin | keep text ≥ 3 mm inside trim |
| Sides | **Double-sided** (front + back), duplex-aligned |
| Neck hole | **Ø 27 mm**, top-centered (see die-line page) |
| Slit | narrow slit from hole to top edge — lets the tag slip onto a filled bottle |
| Stock | **300–350 gsm** matte card (uncoated or matte-laminate) |
| Finish | matte preferred (photo + warm-white read best matte) |
| Colour | file is **RGB** — please convert to CMYK for press, or advise and we resend |
| Crop marks | included on each page |

## Notes
- Colours: Warm White #F5F0EB (background), Wine Red #8C1C1C, Deep Black #1A1A1A,
  Amber Gold #C9A84C (stars). Background must bleed fully — no white border after trim.
- QR must stay crisp black on warm white; do not recolour or add effects. Test-scan a
  printed proof before the full run.
- Hole + slit are die-cut; if the shop can't die-cut, a round 27 mm punch + a short knife
  slit to the top edge works.
